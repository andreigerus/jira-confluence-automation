# Calculator

This project includes a small Python helper module with a `Calculator` class.

## Calculator

The `Calculator.multiply(a, b)` method takes two numbers and returns their product.

Example:

```python
from calculator import Calculator

calculator = Calculator()
result = calculator.multiply(6, 7)
print(result)  # 42
```
